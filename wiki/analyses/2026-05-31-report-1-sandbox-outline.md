# 交付报告① 提纲：决策安全沙箱关键技术

> 对应[研究线③](../entities/decision-security-sandbox.md)。本报告是三份交付物中的技术核心，建议 P3–P4 完成。

## 0. 摘要
一句话定位 + 核心贡献（多层次沙箱 / 全链路监控 / 影子执行 / 主动干预 / 动态测评）+ 关键指标结果。

## 1. 引言
- 问题：智能体"行为能力"带来的决策—执行层风险；传统测试/静态分析的不足。
- 目标：构建"仿真推演—风险评估—主动免疫"一体化决策安全沙箱。
- 与报告②（态势）③（风险体系）的关系：本报告消费前两者的对象与风险标签。

## 2. 总体架构
- 架构图：感知—规划—决策—执行 全链路 × 沙箱研判（静态风险 × 动态态势 × 影子执行）× 主动干预 × 动态测评。
- 与 [Optima-Bench](../entities/optima-bench.md) 的关系：拦截式 Mock 执行器 → 沙箱底座。

## 3. 多层次沙箱构建
- 沙箱分层：高保真 Mock 状态层 / 受限真实执行层 / 影子预演层。
- 基于 Optima-Bench Mock Handler + state 快照的实现路径。
- **风险场景自动生成**：提示注入 / 越权诱导 / 工具投毒 / 陷阱任务 生成器（输入：风险体系；输出：可复现对抗用例）。

## 4. 全链路可解释监控与风险溯源
- "感知—规划—决策—执行"四环节观测点定义。
- 决策 → [风险体系](../entities/agent-decision-risk-taxonomy.md)映射；态势特征（累计风险暴露、高危决策点、异常行为序列检测）。
- **风险溯源**：致害结果 → 定位是哪一步决策、哪类风险（trace 回溯 + 反事实 diff）。

## 5. 影子执行（仿真推演）
- 触发条件：高危 + 不可逆 + 批量/全局。
- 机制：镜像 Mock 状态预演工具调用 → golden-state 差分 → 危害预测。
- 误差与置信度评估。

## 6. 主动干预（主动免疫）
- 研判引擎：规则引擎（确定性策略）+ LLM Judge（语境化研判）混合。
- 四类动作：放行 / 二次确认 / 拦截 / 降级；策略可配置与优先级。
- 干预对任务效用的影响控制。

## 7. 人机混合决策回路与动态测评
- 人机交接点设计（何时升级给人）。
- 动态测评指标：危害拦截率 / 误拦率 / 任务效用保持率 / 攻击防御成功率；pass^k 可靠性。

## 8. 实验与评测
- 测试床：Optima-Bench 581 用例 + 自建安全对抗用例集（≥150 条）。
- 主结果表 + 消融（去掉影子执行 / 去掉态势 / 仅规则 vs 规则+LLM）。
- 典型案例分析（拦截成功 / 误拦 / 漏拦）。

## 9. 结论与展望
贡献小结、局限、后续（更多专业域、真实环境联调、与监管对接）。
