# 总览：智能体应用态势、风险体系与决策安全沙箱

## 背景

智能体（Agent）在大模型"生成内容"之上进一步具备"**行为能力**"——可自主调用工具、操作真实业务系统，风险更多、威胁更大。一方面亟需**跟踪应用态势、建立科学的风险分类分级体系**；另一方面，面对其在复杂开放环境中**自主决策**带来的不可预测风险，传统软件测试与静态分析已无法满足安全评估需求，亟需突破决策过程**高保真模拟、深度风险剖析、主动干预**等关键技术，构建 **"仿真推演—风险评估—主动免疫"一体化** 的决策安全沙箱。

## 三条研究线（↔ 三份交付报告）

### ① 应用态势研判 → 报告②
跟踪调研国内外智能体技术应用发展态势（技术进展 / 应用模式 / 生态组成），建立**重点应用清单**，刻画典型应用形态与安全暴露面。详见 [应用态势研判](../entities/agent-application-situation.md)。

### ② 风险分类分级 → 报告③
按**内生风险 / 外部攻击 / 应用衍生风险**三来源梳理，按**分类分级**原则建立可机读的风险体系框架与应对建议。详见 [决策风险分类分级体系](../entities/agent-decision-risk-taxonomy.md)。

### ③ 决策安全沙箱 → 报告①
构建支持**风险场景自动生成**的**多层次沙箱**，在 **"感知—规划—决策—执行"全链路** 实现可解释监控与风险溯源，对高危不可逆决策做**影子执行**预测危害、再**主动干预**，并建立**人机混合决策回路的动态测评**体系。详见 [决策安全沙箱机制](../entities/decision-security-sandbox.md)。

## 全链路决策安全沙箱（示意）

```
智能体  感知 → 规划 → 决策 → 执行
          │      │      │      │
          └──────┴──────┴──────┘  全链路可解释监控 + 风险溯源
                         │
          [决策安全沙箱]  静态风险体系 × 动态态势 × 影子执行（仿真推演）
                         │
            放行 / 二次确认 / 拦截 / 降级（主动干预·主动免疫）
                         │
                    真实工具执行
                         │
            人机混合决策回路 · 动态测评（防护率 / 误拦 / 效用 / 防御）
```

## 工程底座与评测

以 [Optima-Bench](../entities/optima-bench.md) 为底座（拦截式 Mock 执行器 + golden-state + 行为轨迹 + Harmlessness）。评测以其 581 条专业域用例为测试床，新增"安全对抗用例集"（提示注入 / 越权诱导 / 工具投毒），量化危害拦截率、误拦率、任务效用保持率、攻击防御成功率。详见 [研究计划与考核指标](../analyses/2026-05-30-research-plan-and-kpis.md)。
