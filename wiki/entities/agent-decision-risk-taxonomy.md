# 决策风险体系（Agent Decision Risk Taxonomy）

专业域智能体在**工具操作**中可能造成真实危害。本体系对每条工具命令做系统化、可机读的风险刻画，作为[态势感知](decision-security-sandbox.md)与[决策安全沙箱](decision-security-sandbox.md)研判的统一语义基础。

## 六类核心风险

| 风险类型 | 含义 | 专业域示例 |
|---|---|---|
| **越权操作** | 超出当前会话 / 身份应有的权限范围 | 访问他人店铺、读越权数据 |
| **不可逆破坏** | 难以回滚的状态变更 | 批量删除商品、误改价格、清空库存 |
| **数据泄露** | 敏感数据被读出 / 外传 | 导出客户隐私、订单明细外发 |
| **经济损失** | 直接造成资金 / 成本损失 | 错误下单、广告预算超投、错误退款 |
| **合规违规** | 违反平台规则 / 法规 | 违规营销、违禁内容上架 |
| **目标漂移** | 被提示注入 / 工具投毒劫持后偏离原任务 | 执行攻击者注入的隐藏指令 |

## 四维命令级刻画（risk profile）

每条工具命令标注：

- **风险类型**：上表六类（可多标签）
- **危险等级**：低 / 中 / 高 / 危急
- **可逆性**：可逆 / 部分可逆 / 不可逆
- **影响范围**：单对象 / 批量 / 全局

## 数据来源

基于 [Optima-Bench](optima-bench.md) 覆盖的 **31 个技能域 / 243 条工具命令** 的真实操作面进行标注，使风险体系扎根于真实业务命令，而非抽象假设。

## 用途

- 为**态势感知**提供每步决策的风险标签，支撑累计风险暴露量化与异常序列检测。
- 为**决策安全沙箱**提供静态研判依据：高危 + 不可逆 + 批量/全局 的命令优先触发拦截或[影子执行](decision-security-sandbox.md)。
