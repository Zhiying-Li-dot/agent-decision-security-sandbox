# 决策风险分类分级体系（研究线②）

> 对应交付**研究报告③：智能体风险分类分级分析**。

按**分类分级**原则，对智能体风险建立可机读的风险体系框架，作为[态势研判](agent-application-situation.md)落点与[决策安全沙箱](decision-security-sandbox.md)研判的统一语义基础。

## 三大风险来源（一级分类）

| 来源 | 含义 | 示例 |
|---|---|---|
| **内生风险** | 模型 / 智能体自身缺陷 | 模型幻觉、目标偏移、规划错误 |
| **外部攻击** | 攻击者诱导 / 注入 | 提示注入、工具投毒、越权诱导、陷阱任务 |
| **应用衍生风险** | 行为落到真实系统的危害 | 不可逆破坏、数据泄露、经济损失、合规违规 |

## 二级风险与分级刻画

每条风险/命令进一步标注：

- **二级风险类型**（如：批量删除、误改价、越权读数、广告超投、违规上架……）
- **危险等级**：低 / 中 / 高 / 危急（≥4 级）
- **可逆性**：可逆 / 部分可逆 / 不可逆
- **影响范围**：单对象 / 批量 / 全局
- **应对建议**：监控 / 二次确认 / 拦截 / 降级 / 影子执行

## 数据来源

基于 [Optima-Bench](optima-bench.md) 的 31 技能域 / 243 条工具命令真实操作面进行标注，使"应用衍生风险"扎根于真实业务命令。

## 用途

- 为**态势研判**提供风险落点；
- 为**决策安全沙箱**提供静态研判依据：高危 + 不可逆 + 批量/全局 优先触发拦截或[影子执行](decision-security-sandbox.md)。
