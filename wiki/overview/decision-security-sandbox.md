# 总览：面向专业域智能体的决策安全沙箱

## 问题动机

大模型智能体正从"对话问答"走向"自主调用工具操作真实业务系统"。一旦智能体的**工具调用决策**出错或被诱导，危害直接落到真实世界状态——这是模型对齐 / 内容护栏（让模型"拒答"）覆盖不到的层面。本研究面向专业域智能体，把安全防护下沉到**决策—执行层**。

典型危害：越权访问、不可逆破坏（批量删商品 / 误改价）、数据泄露、经济损失（错误下单 / 广告超投）、被提示注入 / 工具投毒后的目标漂移。详见 [决策风险体系](../entities/agent-decision-risk-taxonomy.md)。

## 三个关键技术问题

1. **风险体系（怎么刻画风险）** → [决策风险体系](../entities/agent-decision-risk-taxonomy.md)
2. **态势感知（怎么实时感知决策与异常）** → 见下"研究内容二"
3. **决策安全沙箱（执行前怎么研判与拦截而不伤效用）** → [决策安全沙箱机制](../entities/decision-security-sandbox.md)

## 技术路线总览

```
指令 → 智能体 → 工具调用决策 ──► [决策安全沙箱]
                                  ├─ 静态：风险体系（命令级 risk profile）
                                  ├─ 动态：态势感知（累计风险/异常序列）
                                  └─ 预测：影子执行（Mock 预演危害）
                                        │
                          放行 / 二次确认 / 拦截 / 降级
                                        │
                                  真实工具执行
```

- **研究内容一**：基于 [Optima-Bench](../entities/optima-bench.md) 的 243 条命令构建命令级风险画像。
- **研究内容二**：在智能体与工具之间插观测层，把每步决策映射到风险体系，构建态势特征（累计风险暴露、高危决策点、异常行为序列检测）。
- **研究内容三**：执行前做"风险体系 × 态势"混合研判，对不可逆高危决策先[影子执行](../entities/decision-security-sandbox.md)预演危害。

## 评测—防御闭环

以 Optima-Bench 的 581 条专业域用例为测试床，新增"安全对抗用例集"（提示注入 / 诱导越权 / 陷阱任务 / 工具投毒），用四项指标量化：危害拦截率、误拦率、任务效用保持率、攻击防御成功率。把"评测"和"防御"闭成环。详见 [研究计划与考核指标](../analyses/2026-05-30-research-plan-and-kpis.md)。

## 与现有工作的关系

- 不同于停留在模型层的对齐 / 红队评测，本研究面向**工具操作决策**的运行时防护。
- 工程上复用并升级已开源的行为评测基础设施 [Optima-Bench](../entities/optima-bench.md)，从"事后评测"走向"运行时防御"。
