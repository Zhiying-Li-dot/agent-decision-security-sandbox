# 智能体应用态势研判（研究线①）

> 对应交付**研究报告②：智能体技术应用发展分析**。

跟踪调研国内外智能体技术应用发展态势，为风险体系与沙箱测评提供"研判什么对象"的基础。

## 研判内容

- **技术进展**：智能体关键技术演进（规划、工具调用、记忆、多智能体协作、协议如 MCP/A2A 等）。
- **应用模式**：智能体在各专业域的落地模式与价值场景。
- **生态组成**：模型、框架、工具/插件、运行时、平台等生态角色。
- **重点应用清单**：归纳值得重点关注的智能体应用，形成清单。

## 典型应用形态与安全暴露面

| 形态 | 说明 | 主要暴露面 |
|---|---|---|
| 工具调用型 | 通过 API/CLI 操作业务系统 | 越权、不可逆破坏、经济损失 |
| 浏览器 / GUI 型 | 操作网页 / 桌面 | 提示注入、敏感数据读取 |
| 多智能体协作型 | 多体协同、消息传递 | 工具投毒、目标漂移、协作放大 |

## 与其他研究线的关系

应用态势研判界定**对象与暴露面** → 为 [风险分类分级](agent-decision-risk-taxonomy.md) 提供风险落点 → 为 [决策安全沙箱](decision-security-sandbox.md) 提供需要监控/测评的真实操作面。[Optima-Bench](optima-bench.md) 的 31 技能域 / 243 命令即一组已落地的工具调用型操作面样本。
