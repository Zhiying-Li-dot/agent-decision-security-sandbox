## 0. 摘要
风险分类分级体系的总体结构 + 一级三类 + 分级方法要点。

## 1. 引言
- 动机：智能体风险"更多、更大"，缺乏系统化分类分级。
- 范围与方法论：分类分级原则；可参照对标的框架（OWASP LLM/Agentic、MITRE ATLAS 等，如适用）。

## 2. 风险来源（一级分类）
- **内生风险**：模型缺陷、幻觉、目标偏移、规划/推理错误。
- **外部攻击**：提示注入、工具投毒、越权诱导、陷阱任务、对抗样本。
- **应用衍生风险**：不可逆破坏、数据泄露、经济损失、合规违规。

## 3. 二级风险目录
- 每个一级类下列二级风险项，统一字段：定义 / 触发条件 / 示例 / 可逆性 / 影响范围 / 关联攻击。
- 目标：二级风险 ≥ 12 项，形成可机读目录。

## 4. 风险分级方法
- 分级维度：危险等级、可逆性、影响范围（单对象/批量/全局）、可利用性。
- 分级矩阵 → 危急 / 高 / 中 / 低（≥4 级）。
- 分级一致性校验（多标注者 / 规则一致性）。

## 5. 命令级风险画像
- 标注 schema（风险类型 + 等级 + 可逆性 + 影响范围 + 应对建议）。
- 以 [Optima-Bench](../entities/optima-bench.md) 243 条命令为标注对象，给出示例与统计分布。

## 6. 应对建议与沙箱对接
- 每类风险 → 推荐处置（监控 / 二次确认 / 拦截 / 降级 / 影子执行）。
- 与[决策安全沙箱](../entities/decision-security-sandbox.md)研判规则的映射表（风险体系即沙箱的静态研判依据）。

## 7. 对标与差距
