# 交付报告② 提纲：智能体技术应用发展分析

> 对应[研究线①](../entities/agent-application-situation.md)。综述/态势类报告，建议 P1 完成初稿、全程滚动更新。

## 0. 摘要
智能体技术与应用发展态势的总体判断 + 重点应用清单要点。

## 1. 引言
- 背景：智能体成为 AI 落地主要形式。
- 范围与方法：调研来源（论文 / 厂商 / 开源 / 报告）、时间窗（重点 2024–2026）、筛选标准。

## 2. 技术进展
- 核心能力演进：规划与推理、工具调用（function calling）、记忆、反思/自我纠错、多智能体协作。
- 关键协议与框架：MCP、A2A 等互联协议；主流 agent 框架与运行时。
- 代表性系统与模型能力对比（可引用公开基准，如工具调用 / agentic 评测）。

## 3. 应用模式
- 按场景：编程、办公自动化、客服、电商运营、科研、运维等。
- 按形态：工具调用型 / 浏览器·GUI 型 / 多智能体协作型 / 嵌入式（设备·终端）。
- 价值与成熟度评估。

## 4. 生态组成
- 分层图谱：模型层 → 框架/编排层 → 工具·插件层 → 运行时/沙箱 → 平台 → 评测。
- 关键角色与代表项目；开源 vs 闭源格局。

## 5. 重点应用清单（核心交付）
- 筛选标准：影响面 × 风险面 × 代表性。
- 清单表：应用 / 形态 / 能力边界 / 典型工具操作面 / **安全暴露面**（接[风险体系](../entities/agent-decision-risk-taxonomy.md)）。
- 案例：以 [Optima-Bench](../entities/optima-bench.md) 的 31 技能域作为"工具调用型"应用面的一个具体样本。

## 6. 发展趋势与安全启示
- 趋势：能力增强、自治度提升、多体化、协议标准化。
- 安全启示：自治度↑ → 决策—执行层风险↑ → 引出报告③与报告①的必要性。

## 7. 结论
态势总判断 + 对后续风险体系与沙箱研究的支撑结论。
